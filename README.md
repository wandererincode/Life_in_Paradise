# Greedflation — Interactive Net Art (p5.js)

## Folder Structure
- `index.html` — Loads p5.js and mounts the responsive 16:9 canvas.
- `style.css` — Full-viewport dark gallery framing with zero scrollbars.
- `sketch.js` — Complete state machine (`MENU` -> `PLAY` -> `GAMEOVER`), inflation price ticker, money pipeline particles, and corporate profit tower.

## How to Run Locally
1. Unzip the folder and open it in VS Code (or any editor).
2. Run with **Live Server** (or `python3 -m http.server 8000` in Terminal on your MacBook Air) and open Chrome.
3. For 4K gallery exhibition (The Void @ UVic), host on GitHub Pages / Netlify / Vercel and open in Chrome Kiosk Mode.
